What I doodle

Write out Pascal's triangle, then keep only whether each number is odd. Sixteen rows in, a Sierpinski triangle has appeared, made of nothing but ones and zeros.

There is a clean reason: a binomial coefficient is odd exactly when the bits of k sit inside the bits of n. So the pattern is really about binary all along, which is the same joke the Thue–Morse word keeps telling on the rest of this site.
